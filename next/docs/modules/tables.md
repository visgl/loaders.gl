Import metadata from `@loaders.gl/tables` or a bare format subpath such as `@loaders.gl/tables/csv`. Import parser-bearing loaders from named implementation subpaths such as `@loaders.gl/tables/csv-loader`. See [Get Started](https://loaders.gl/next/docs/developer-guide/get-started.md#install-packages-import-subpaths) for installation and loading patterns.

BSON document loaders and codecs live in [`@loaders.gl/documents`](https://loaders.gl/next/docs/modules/documents.md). Parquet BSON logical columns use that codec automatically.
