# 🧪 @loaders.gl/scientific/adsb

![Status: Experimental](https://img.shields.io/badge/Status-Experimental-orange.svg?style=flat-square)

Read ADS-B aircraft state snapshots in two JSON layouts. The format subpath exports `ADSBFormat`, `ADSBLoader` metadata, and types. The `/adsb/bundled` subpath also exports the parser-bearing loader.

* [ADSBLoader](https://loaders.gl/next/docs/modules/scientific/adsb/api-reference/adsb-loader.md)
* [ADS-B aircraft state JSON](https://loaders.gl/next/docs/modules/scientific/adsb/formats/adsb.md)
