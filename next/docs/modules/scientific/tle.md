# 🧪 @loaders.gl/scientific/tle

Read satellite orbit elements in the two-line element set (TLE) format. This entry point exports `TLELoader`, `TLELoaderWithParser` and TLE helpers. The loader returns rows with the CCSDS OMM keyword names, the same as [`OMMLoader`](https://loaders.gl/next/docs/modules/scientific/omm/api-reference/omm-loader.md).
