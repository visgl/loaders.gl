# 🧪 @loaders.gl/scientific/gtfs

![Status: Experimental](https://img.shields.io/badge/Status-Experimental-orange.svg?style=flat-square)

Read GTFS Schedule ZIP feeds as typed CSV tables, stop points, and route shapes. The format subpath exports `GTFSFormat`, `GTFSLoader` metadata, and types. The `/gtfs/bundled` subpath also exports the parser-bearing loader.

* [GTFSLoader](https://loaders.gl/next/docs/modules/scientific/gtfs/api-reference/gtfs-loader.md)
* [GTFS Schedule ZIP](https://loaders.gl/next/docs/modules/scientific/gtfs/formats/gtfs.md)
