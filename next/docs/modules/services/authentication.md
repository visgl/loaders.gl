# @loaders.gl/services/authentication

Create credentials and authentication handlers for supported services.

## API[​](#api "Direct link to API")

| Export                        | Kind    |
| ----------------------------- | ------- |
| `createMapboxCredential`      | Utility |
| `createGoogleMapsCredential`  | Utility |
| `createCesiumIonCredential`   | Utility |
| `MapboxAuthentication`        | Utility |
| `GoogleMapsAuthentication`    | Utility |
| `CesiumIonAuthentication`     | Utility |
| `ServiceCredentialOptions`    | Type    |
| `MapboxCredentialOptions`     | Type    |
| `GoogleMapsCredentialOptions` | Type    |
| `CesiumIonCredentialOptions`  | Type    |

See the [services module](https://loaders.gl/next/docs/modules/services.md) for installation and related entrypoints.
