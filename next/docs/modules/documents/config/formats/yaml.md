# YAML

## loaders.gl support[​](#loadersgl-support "Direct link to loaders.gl support")

| Type   | API                                                                                                     |
| ------ | ------------------------------------------------------------------------------------------------------- |
| Loader | [`YAMLLoader`](https://loaders.gl/next/docs/modules/documents/config/api-reference/yaml-loader.md) |

YAML is a human-friendly data serialization language commonly used for configuration documents.

* *[`@loaders.gl/documents`](https://loaders.gl/next/docs/modules/documents/config.md)*
* *[`YAMLLoader`](https://loaders.gl/next/docs/modules/documents/config/api-reference/yaml-loader.md)*
* *[YAML specification](https://yaml.org/spec/)*

The loaders.gl YAML parser supports common block and flow mappings/sequences, quoted and plain scalars, comments, block scalars, YAML 1.1/1.2 scalar resolution, and duplicate-key validation.
