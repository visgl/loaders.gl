# @loaders.gl/traces/zipkin

Read and write Zipkin traces and annotations.

```
import {ZipkinTraceLoader, ZipkinTraceWriter} from '@loaders.gl/traces/zipkin';
```

## API[​](#api "Direct link to API")

| Export                        | Kind   |
| ----------------------------- | ------ |
| `ZipkinTraceLoader`           | Loader |
| `ZipkinTraceLoaderOptions`    | Type   |
| `ZipkinTraceWriter`           | Writer |
| `ZipkinTraceWriterOptions`    | Type   |
| `ZipkinAnnotation`            | Type   |
| `ZipkinEndpoint`              | Type   |
| `ZipkinSpan`                  | Type   |
| `ZipkinTraceLoaderWithParser` | Loader |

See the [traces module](https://loaders.gl/next/docs/modules/traces.md) for installation and related entrypoints.
