# @loaders.gl/traces/otlp

Read and write OpenTelemetry traces in JSON and Protobuf form.

```
import {OtlpTraceJsonLoader, OtlpTraceLoader, OtlpTraceJsonWriter, OtlpTraceWriter} from '@loaders.gl/traces/otlp';
```

## API[​](#api "Direct link to API")

| Export                          | Kind   |
| ------------------------------- | ------ |
| `OtlpTraceJsonLoader`           | Loader |
| `OtlpTraceLoader`               | Loader |
| `OtlpTraceLoaderOptions`        | Type   |
| `OtlpEventArrowTable`           | Type   |
| `OtlpLinkArrowTable`            | Type   |
| `OtlpResourceArrowTable`        | Type   |
| `OtlpScopeArrowTable`           | Type   |
| `OtlpSpanArrowTable`            | Type   |

| `OtlpTraceWriter`               | Writer |

| `OtlpTraceLoaderWithParser`     | Loader |
