# @loaders.gl/splats/ksplat

Read KSPLAT Gaussian splat data.

```
import {KSPLATFormat, KSPLATLoader} from '@loaders.gl/splats/ksplat';
```

## API[​](#api "Direct link to API")

| Export                   | Kind    |
| ------------------------ | ------- |
| `KSPLATFormat`           | Utility |
| `KSPLATLoader`           | Loader  |
| `KSPLATLoaderWithParser` | Loader  |
