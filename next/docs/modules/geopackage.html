Geospatial database module

@loaders.gl/geopackage

Open a GeoPackage without hiding its layers.

GeoPackage is a SQLite-based container for vector features, tiles, and metadata. The module exposes its tables and layers directly, with a source path for discovering and reading selected data.

GeoPackage module details

The sections below cover installation, loaders, sources, layers, tables, and attribution.

The @loaders.gl/geopackage module handles the OGC GeoPackage format.

Installation​

npm install @loaders.gl/geopackage

Loaders and Writers​

Loader / SourceDescription
GeoPackageLoaderLoads GeoPackage files and exposes their tables and layers.
GeoPackageSourceProvides access to GeoPackage tables as a data source.
