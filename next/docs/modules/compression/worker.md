# @loaders.gl/compression/worker

Run compression tasks in workers.

```
import {CompressionWorker, compressOnWorker} from '@loaders.gl/compression/worker';
```

## API[​](#api "Direct link to API")

| Export                     | Kind    |
| -------------------------- | ------- |
| `CompressionWorkerOptions` | Type    |
| `CompressionWorker`        | Utility |
| `compressOnWorker`         | Utility |

See the [compression module](https://loaders.gl/next/docs/modules/compression.md) for installation and related entrypoints.
