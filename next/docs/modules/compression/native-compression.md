# @loaders.gl/compression/native-compression

APIs for NATIVE-COMPRESSION data in the compression module.

```
import {compressBatchesWithNativeCompressionStream, compressWithNativeCompressionStream} from '@loaders.gl/compression/native-compression';
```

## API[​](#api "Direct link to API")

| Export                                       | Kind    |
| -------------------------------------------- | ------- |
| `compressBatchesWithNativeCompressionStream` | Utility |
| `compressWithNativeCompressionStream`        | Utility |
| `NativeCompressionFormat`                    | Type    |

See the [compression module](https://loaders.gl/next/docs/modules/compression.md) for installation and related entrypoints.
