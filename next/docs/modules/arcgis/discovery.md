# @loaders.gl/arcgis/discovery

Discover ArcGIS services and select their loaders.

```
import {ARCGIS_LOADERS, getArcGISLoader} from '@loaders.gl/arcgis/discovery';
```

## API[​](#api "Direct link to API")

| Export                         | Kind    |
| ------------------------------ | ------- |
| `discoverArcGISCapabilities`   | Utility |
| `selectArcGISService`          | Utility |
| `getArcGISServices`            | Utility |
| `ArcGISService`                | Type    |
| `ArcGISServiceCapabilities`    | Type    |
| `ArcGISCapabilityGraph`        | Type    |
| `ArcGISServiceSelection`       | Type    |
| `ArcGISCapabilityGraphOptions` | Type    |
| `ArcGISLoader`                 | Type    |
| `ARCGIS_LOADERS`               | Utility |
| `getArcGISLoader`              | Loader  |
