# @loaders.gl/arcgis/scene-service

Access ArcGIS scene services.

```
import {ArcGISSceneServerLoader} from '@loaders.gl/arcgis/scene-service';
```

| Export                              | Kind    |
| ----------------------------------- | ------- |
| `ArcGISSceneServerLoader`           | Loader  |
| `ArcGISSceneServerSource`           | Source  |
| `ArcGISSceneServerQueryError`       | Utility |
| `ArcGISSceneServerLoaderOptions`    | Type    |
| `ArcGISSceneQueryOptions`           | Type    |
| `ArcGISSceneQueryResult`            | Type    |
| `ArcGISSceneServerLoaderWithParser` | Loader  |
