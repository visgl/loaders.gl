# @loaders.gl/arcgis/image-service

Access ArcGIS imagery services and image tiles.

```
import {ArcGISImageServerLoader, ArcGISImageTileLoader} from '@loaders.gl/arcgis/image-service';
```

## API[​](#api "Direct link to API")

| Export                              | Kind   |
| ----------------------------------- | ------ |
| `ArcGISImageServerLoader`           | Loader |
| `ArcGISImageSource`                 | Source |
| `ArcGISImageTileLoader`             | Loader |
| `ArcGISImageTileSource`             | Source |
| `ArcGISExportImageParameters`       | Type   |
| `ArcGISImageServerLoaderOptions`    | Type   |
| `ArcGISImageTileLoaderOptions`      | Type   |
| `ArcGISImageServerLoaderWithParser` | Loader |
| `ArcGISImageTileLoaderWithParser`   | Loader |
