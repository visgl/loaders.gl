# YAML

YAML is a human-friendly data serialization language commonly used for configuration documents.

* *[`@loaders.gl/config`](https://loaders.gl/next/docs/modules/config.md)*
* *[`YAMLLoader`](https://loaders.gl/next/docs/modules/config/api-reference/yaml-loader.md)*
* *[YAML specification](https://yaml.org/spec/)*

The loaders.gl YAML parser supports common block and flow mappings/sequences, quoted and plain scalars, comments, block scalars, YAML 1.1/1.2 scalar resolution, and duplicate-key validation.
