# @loaders.gl/graphs/gexf

Read GEXF graph documents into node and edge tables with their authored metadata.

```
import {GEXFLoader} from '@loaders.gl/graphs/gexf';
```

## API[​](#api "Direct link to API")

| Export                 | Kind   |
| ---------------------- | ------ |
| `GEXFLoader`           | Loader |
| `GEXFLoaderOptions`    | Type   |
| `GEXFMetadata`         | Type   |
| `GEXFOutput`           | Type   |
| `GEXFLoaderWithParser` | Loader |

See the [graphs module](https://loaders.gl/next/docs/modules/graphs.md) for installation and related entrypoints.
