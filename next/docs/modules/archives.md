# Archives

`@loaders.gl/archives` provides ZIP and TAR archive loaders and writers. Install `@loaders.gl/core` and `@loaders.gl/archives`. The root exports metadata loaders and writers; import format-specific helpers from [`@loaders.gl/archives/zip`](https://loaders.gl/next/docs/modules/archives/zip.md) or [`@loaders.gl/archives/tar`](https://loaders.gl/next/docs/modules/archives/tar.md).
