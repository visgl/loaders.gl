# I3S Explorer

I3S Explorer is an open source web app for viewing and inspecting I3S scene layers. It uses loaders.gl and deck.gl to render scenes such as buildings and textured 3D objects.

* [Open I3S Explorer](https://i3s.loaders.gl/viewer?tileset=turanga-library) to explore the Tūranga Library scene.
* [View the source code and setup instructions](https://github.com/visgl/loaders.gl-showcases) in the separate `visgl/loaders.gl-showcases` repository.
* [Read the I3S format guide](https://loaders.gl/next/docs/modules/tiles-3d/i3s/formats/i3s.md) for loaders.gl support.
