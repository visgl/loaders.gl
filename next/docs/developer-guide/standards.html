How to read the matrix

A standard name is not a blanket promise.

Support is recorded at the format, protocol, and capability level. Follow the linked module or specification for the exact version, profile, and execution boundary.

OGC Web Standards​

OGC ProtocolsSupportedDescription
CSW (Catalog Service for the Web) protocol@loaders.gl/wmsprotocol for reading a catalog of geospatial assets and services from a URL.
WMS (Web Map Service) protocol@loaders.gl/wmsprotocol for serving geo-referenced map images over the internet.
WFS (Web Feature Service) protocol@loaders.gl/wmsprotocol for serving geo-referenced map features (geometries) over the internet.
WMTS (Web Map Tile Service) protocol@loaders.gl/wmsprotocol for serving pre-rendered or run-time computed georeferenced map tiles over the Internet.
WCS (Web Coverage Service)✕Load coverage data (e.g. geotiff images for satellite data) from a server.
WMC✕Used in WMS clients to save the configuration of maps and to load them again later. Can also be exchanged between different clients.
OWS Context✕Allows configured information resources to be passed between applications primarily as a collection of services.
