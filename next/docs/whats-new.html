What's new

From cloud data to visualization.

loaders.gl 5 brings catalog discovery, columnar queries, raster access, and tile authoring into one data toolkit.

Upgrade guide ↗Try the examples ↗

v5.0​

loaders.gl 5 organizes loaders, writers, and sources by data family. Install a package and import the format you use. See the Upgrade Guide for stable v4 migrations.

  • Cloud and table data. Table sources support column and row selection across Parquet, Arrow, and lakehouse formats. Core queries push supported filters and projections to the source. SQL provides an opt-in DuckDB integration.
  • Raster and scientific data. Raster supports range reads and terrain meshes. Scientific groups multidimensional arrays and VTK, NRRD, and PDB formats.
  • GeoZarr pyramids. GeoZarrRasterSource opens xarray level groups, preserves CF CRS definitions, reads CF nodata with optional Zarr fill values, and selects native overviews by viewport. Pass zarr.store to read GeoZarr metadata and chunks through a custom Zarrita store.
  • GPU raster styling. RasterSourceLayer can render single-band rasters on WebGL2 and WebGPU with CPU-matched default colors, per-raster percentile stretching, and texel picking. Set valueRange for a fixed stretch.
  • Projected raster sources. RasterSourceLayer renders supported projected CRSs, including UTM, in MapView and GlobeView with either CPU or GPU styling.
  • GeoTIFF transparency. RasterSourceLayer honors alpha bands in RGB and grayscale GeoTIFFs, and shows tagged 8-bit RGB as stored. Grayscale with alpha uses CPU rendering.
  • 3D content and tiles. Scene groups glTF, Draco, and mesh formats. Tile Converter defaults to the v5 engine. The TileMatrix adapter adds coarse-to-fine levels, center-based parents, and optional geographic outlines for deck.gl.
  • 🧪 Satellite orbit elements (experimental). OMMLoader reads the SGP4 subset of CCSDS OMM in JSON and KVN. It validates GP metadata and epoch dates. In KVN, it accepts metadata and data delimiters and skips optional blocks such as covariance. TLELoader reads two-line element sets. Both return one table schema with the OMM keyword names.
  • 🧪 Vessel and aircraft positions. AISLoader reads NMEA maritime reports, and ADSBLoader reads aircraft state snapshots. Both return Arrow or object-row tables.
  • 🧪 Transit schedules. GTFSLoader reads GTFS Schedule ZIP feeds as typed tables, stop points, and route shapes.
  • 🧪 Realtime transit. GTFSRealtimeLoader reads GTFS Realtime snapshots as vehicle tables or decoded feeds with duplicate trip IDs, platform assignments, alerts, and realtime shapes, stops, and trip modifications.
  • Documents and images. Documents groups text and structured formats. Images adds OpenEXR, color lookup tables, and measured lighting profiles.
  • Optional implementations. Use metadata loaders with load() and parse(). Import a format's bundled loader when you need its parser immediately, such as with parseSync().

v4.5​

Added Gaussian splat loaders, Chrome Trace parsing, experimental TypeScript Parquet, and Mapbox and MapLibre style loading.

v4.4​

Added MapLibre Tile support and unified texture outputs, including Radiance HDR.

v4.3​

Improved loader type inference and introduced typed source and range request interfaces.

v4.2​

Improved loader object typing and moved the website examples to deck.gl v9.

v4.1​

Added GeoArrow loading and required Apache Arrow 15 or later.

v4.0​

Added typed loaders, more writers, file format documentation, and support for Node.js 18 and 20.

v3.4​

Moved the documentation to Docusaurus and upgraded to TypeScript 5.

v3.3​

Added official Vite support and moved most examples to Vite.

v3.2​

Added support for the recommended Arrow file and stream MIME types.

v3.1​

Added KTX2 support to BasisLoader and introduced KTX2BasisWriter.

v3.0​

Improved TypeScript support and expanded typed loaders and options.

v2.3​

Added Shapefile loading, more compression codecs, and binary geospatial output.

v2.2​

Published TypeScript declarations for packages with public functions and classes.

v2.1​

Expanded geospatial loaders and 3D content support.

v2.0​

Added loader-specific options, composite loaders, and dynamic loading of heavy decoders.

v1.3​

Improved 3D Tiles support and the glTF 2 parser.

v1.2​

Added binary file auto-detection and improved Arrow support in Node.

v1.1​

Introduced GLTFLoader and early 3D Tiles support.

v1.0​

Initial release.

See the changelog for release-by-release details.
