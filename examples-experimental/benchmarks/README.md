# loaders.gl-benchmark-example

Interactive loaders.gl parsing benchmarks.

Use Node.js 20.19+ or 22.12+. Install the repository dependencies, then run
`yarn build` and `yarn build-workers` from the root. Install this example's
dependencies with `npm install`, then run `npm start` here.
The benchmarks use test fixtures and may fetch data from the public repository.
Use `npm run build` to create a production build.

To run a subset, add a query such as `?module=crypto` to the URL.
