# mapbox-3dtiles

Render 3D Tiles with loaders.gl, Mapbox GL, and Three.js.

Supported formats: 3D Tiles.

Use Node.js 20.19+ or 22.12+. Install dependencies with
`npm install --legacy-peer-deps` (the existing loaders.gl alpha packages have
inconsistent peer dependency versions), set `VITE_MAPBOX_ACCESS_TOKEN` to a
Mapbox access token, and run `npm start`. Use `npm run build` for a production build.
