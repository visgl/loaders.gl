Generate selected tiles from a GeoJSON, GeoArrow IPC/Feather or byte GeoTIFF dataset.
Use the offline sample, drop a local file, or enter a CORS-enabled HTTP(S) URL. Choose an area,
one zoom and a payload format, then generate and download the PMTiles archive. Open the result in
[the PMTiles viewer](/examples/tiles/pmtiles).

The example uses the existing [GeoArrow authoring API](/docs/modules/pmtiles/api-reference/geoarrow-pmtiles)
for MVT/MLT and [raster authoring API](/docs/modules/pmtiles/api-reference/raster-pmtiles) for PNG.

**Bounded export:** 4 GiB (minus one byte) whole-vector input, 50,000 vector rows, 100,000 requested tile addresses,
and 4 GiB (minus one byte) archive output. It exports whole intersecting tiles rather than cropping to the exact
requested bounds. GeoTIFF/COG URLs use range reads with a shared 4 GiB (minus one byte) requested-range budget (including coalescing gaps and failed reads);
Local and remote raster files can be larger because only selected regions are read. Servers must support HTTP 206 and CORS, and expose the `Content-Range` response header. Vector inputs are read
completely before conversion.
These budgets do not cap peak heap; decompression and parsing can allocate before result limits.
Input reading, parsing, tiling and encoding run in a disposable module worker, keeping the page
responsive. Cancel terminates computation immediately; retry starts a fresh worker. No data is uploaded.

GeoTIFF conversion reuses the raster region planner behind the
[common scan architecture](/docs/developer-guide/common-scan-architecture). It selects source
bands and native overviews for each destination tile, while conversion handles sampling and PNG/PMTiles encoding.

The live progress panel shows the current stage and XYZ address, inspected addresses, source bytes and elapsed time. HTTP range and whole-vector reads report bytes; local raster range reads are labeled “Local file” because that transport does not expose byte counters. Counts include empty addresses; reading and parsing remain indeterminate. **Finish & download** stops selecting new tiles, completes any in-flight tile, and packages the completed subset. **Cancel** immediately terminates the worker and discards the export. An all-empty subset cannot produce an archive. Counter updates are throttled to ten per second; stage changes and the first completed address are reported immediately. The worker yields between tiles at least every 16 ms so Finish messages can be received.
