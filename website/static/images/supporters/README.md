# Supporter logos

Foursquare and CARTO retain the existing logos from the [vis.gl asset repository](https://github.com/visgl/deck.gl-data/tree/master/images/logos), now served locally.

Action Engine uses its [official website wordmark](https://actionengine.com/case-studies/ae-logo.svg).

The component uses equal frames and optical sizing to account for intrinsic margins without altering the artwork.

Uber retains the existing website wordmark from `website/static/images/uber-logo.png`.
