# Guide

Start with [Get Started](./get-started.md), then explore the concepts and module guides that match your application. The guides explain how to load, write, and work with data; each module's API section documents its package exports and subpaths.

## Foundations

- [Get Started](./get-started.md): install loaders.gl and load your first dataset.
- [3D data formats](./3d-data-formats.md): choose formats for meshes, point clouds, and tiled scenes.
- [JavaScript APIs](./concepts/javascript-apis.md): understand the asynchronous, synchronous, and streaming APIs.
- [Streaming](./concepts/streaming.md): process data incrementally.
- [Worker threads](./concepts/worker-threads.md): move parsing off the main thread.

## Module guides and API

Browse [Modules](../modules/README.md) by data family. Each module header opens its overview. Guide pages cover workflows and concepts, while API section headers open the main package and subpath pages. Modules with a single guide link directly to that page.

- [Core](../modules/core/README.md): loading, writing, sources, and shared utilities.
- [Tables](../modules/tables/README.md): tabular data and Arrow.
- [Geospatial](../modules/geospatial/README.md): geospatial formats and geometry.
- [Images](../modules/images/README.md): images, textures, and video.
- [3D Tiles](../modules/tiles-3d/README.md): tiled datasets, runtime concepts, and tutorials.
- [Services](../modules/services/README.md): authentication and remote data access.
- [ArcGIS](./arcgis/README.md): ArcGIS service workflows.
