# @loaders.gl/compression/brotli

APIs for BROTLI data in the compression module.

```
import {BrotliCompressor, BrotliDecompressor} from '@loaders.gl/compression/brotli';
```

## API[​](#api "Direct link to API")

| Export                      | Kind    |
| --------------------------- | ------- |
| `BrotliCompressor`          | Utility |
| `BrotliDecompressor`        | Utility |
| `BrotliCompressorOptions`   | Type    |
| `BrotliDecompressorOptions` | Type    |
