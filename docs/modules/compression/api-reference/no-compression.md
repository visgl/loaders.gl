# NoCompression

<p class="badges">
  <img src="https://img.shields.io/badge/Deprecated-v5.0-orange.svg?style=flat-square" alt="Deprecated in v5.0" />
</p>

`NoCompression` is the combined pass-through compatibility transform. It returns the input
unchanged.

New code should import `NoCompressor` from `@loaders.gl/compression/no-compressor` or
`NoDecompressor` from `@loaders.gl/compression/no-decompressor`.

## Interface

Implements the deprecated combined [`Compression`](./compression) API.
