# 🧪 @loaders.gl/scientific/ais

![Status: Experimental](https://img.shields.io/badge/Status-Experimental-orange.svg?style=flat-square)

Read maritime Automatic Identification System (AIS) reports from NMEA text logs. The format subpath exports `AISFormat`, `AISLoader` metadata, and types. The `/ais/bundled` subpath also exports the parser-bearing loader.

* [AISLoader](https://loaders.gl/docs/modules/scientific/ais/api-reference/ais-loader.md)
* [AIS format](https://loaders.gl/docs/modules/scientific/ais/formats/ais.md)
