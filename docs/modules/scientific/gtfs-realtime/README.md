Read vehicle positions, trip updates, and service alerts from GTFS Realtime feeds.
The format subpath exports `GTFSRealtimeFormat`, `GTFSRealtimeLoader` metadata, and types.
The `/gtfs-realtime/bundled` subpath also exports the parser-bearing loader.
