# 🧪 @loaders.gl/scientific/gtfs-realtime

![Status: Experimental](https://img.shields.io/badge/Status-Experimental-orange.svg?style=flat-square)

Read vehicle positions, trip updates, and service alerts from GTFS Realtime feeds. The format subpath exports `GTFSRealtimeFormat`, `GTFSRealtimeLoader` metadata, and types. The `/gtfs-realtime/bundled` subpath also exports the parser-bearing loader.

* [GTFSRealtimeLoader](https://loaders.gl/docs/modules/scientific/gtfs-realtime/api-reference/gtfs-realtime-loader.md)
* [GTFS Realtime protobuf](https://loaders.gl/docs/modules/scientific/gtfs-realtime/formats/gtfs-realtime.md)
