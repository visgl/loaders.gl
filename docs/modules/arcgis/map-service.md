# @loaders.gl/arcgis/map-service

Access ArcGIS map tiles.

```
import {ArcGISMapTileLoader} from '@loaders.gl/arcgis/map-service';
```

## API[​](#api "Direct link to API")

| Export                          | Kind   |
| ------------------------------- | ------ |
| `ArcGISMapTileLoader`           | Loader |
| `ArcGISMapTileSource`           | Source |
| `ArcGISMapTileLoaderOptions`    | Type   |
| `ArcGISMapTileLoaderWithParser` | Loader |
