Read GTFS Schedule ZIP feeds as typed CSV tables, stop points, and route shapes.
The format subpath exports `GTFSFormat`, `GTFSLoader` metadata, and types.
The `/gtfs/bundled` subpath also exports the parser-bearing loader.

- [GTFS Schedule ZIP](./formats/gtfs.md)
