# @loaders.gl/geospatial/omm

Read satellite orbit mean elements in the CCSDS Orbit Mean-Elements Message (OMM) format. This
entry point exports `OMMLoader`, `OMMLoaderWithParser`, the shared orbit element row schema and
small helpers.

- [OMMLoader](./api-reference/omm-loader.md)
- [OMM format](./formats/omm.md)
- [TLELoader](../tle/api-reference/tle-loader.md) returns the same row schema from two-line
  element sets.
