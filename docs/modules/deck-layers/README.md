# deck.gl Layers

`@loaders.gl/deck-layers` contains source-oriented deck.gl layers for displaying data from loaders.gl sources. The package is currently private while its APIs are prepared for upstreaming to deck.gl-community.

The `SourceLayer` selects a supplied source loader and dispatches to the appropriate layer for raster, vector, point cloud, and tiled data. See the [package README](https://github.com/visgl/loaders.gl/tree/master/modules/deck-layers) for usage and supported layers.
