# @loaders.gl/images/radiance-hdr

APIs for RADIANCE-HDR data in the images module.

```
import {RadianceHDRFormat, RadianceHDRLoaderOptions, RadianceHDRLoader} from '@loaders.gl/images/radiance-hdr';
```

## API[​](#api "Direct link to API")

| Export                        | Kind    |
| ----------------------------- | ------- |
| `RadianceHDRLoaderOptions`    | Type    |
| `RadianceHDRLoaderWithParser` | Loader  |
| `RadianceHDRLoader`           | Loader  |
| `RadianceHDRFormat`           | Utility |
| `RadianceHDRMetadata`         | Type    |
