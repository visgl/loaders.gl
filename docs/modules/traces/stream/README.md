# @loaders.gl/traces/stream

Publish incremental trace snapshots through a shared streaming session.

```typescript
import {createTraceStreamSession} from '@loaders.gl/traces/stream';
```

## API

| Export | Kind |
| --- | --- |
| `createTraceStreamSession` | Utility |
| `TraceStreamChunk` | Type |
| `TraceStreamPublishedSnapshot` | Type |
| `TraceStreamReplaceSnapshot` | Type |
| `TraceStreamSession` | Type |
| `TraceStreamSessionListener` | Type |
| `TraceStreamSessionOptions` | Type |

See the [traces module](/docs/modules/traces) for installation and related entrypoints.
