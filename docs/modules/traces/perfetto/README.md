# @loaders.gl/traces/perfetto

Read and write Perfetto trace data and its typed Arrow tables.

```typescript
import {PerfettoTraceLoader} from '@loaders.gl/traces/perfetto';
import {PerfettoTraceWriter} from '@loaders.gl/traces/perfetto/bundled';
```

## API

| Export | Kind |
| --- | --- |
| `PerfettoTraceLoader` | Loader |
| `PerfettoTraceLoaderOptions` | Type |
| `PerfettoProcessArrowTable` | Type |
| `PerfettoSliceArrowTable` | Type |
| `PerfettoThreadArrowTable` | Type |
| `PerfettoTrace` | Type |
| `PerfettoTraceBatch` | Type |
| `PerfettoTraceTableName` | Type |
| `PerfettoTrackArrowTable` | Type |
| `PerfettoTraceWriter` | Writer |
| `PerfettoTraceWriterOptions` | Type |
| `PerfettoTraceLoaderWithParser` | Loader |
