# @loaders.gl/traces/jaeger

Read and write Jaeger traces and their span metadata.

```typescript
import {JaegerTraceLoader} from '@loaders.gl/traces/jaeger';
import {JaegerTraceWriter} from '@loaders.gl/traces/jaeger/bundled';
```

## API

| Export | Kind |
| --- | --- |
| `JaegerTraceLoader` | Loader |
| `JaegerTraceLoaderOptions` | Type |
| `JaegerTraceWriter` | Writer |
| `JaegerTraceWriterOptions` | Type |
| `JaegerLog` | Type |
| `JaegerProcess` | Type |
| `JaegerQueryResponse` | Type |
| `JaegerSpan` | Type |
| `JaegerSpanReference` | Type |
| `JaegerTag` | Type |
| `JaegerTrace` | Type |
| `JaegerTraceLoaderWithParser` | Loader |

See the [traces module](/docs/modules/traces) for installation and related entrypoints.
