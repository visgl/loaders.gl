# @loaders.gl/traces/zipkin

Read and write Zipkin traces and annotations.

```typescript
import {ZipkinTraceLoader} from '@loaders.gl/traces/zipkin';
import {ZipkinTraceWriter} from '@loaders.gl/traces/zipkin/bundled';
```

## API

| Export | Kind |
| --- | --- |
| `ZipkinTraceLoader` | Loader |
| `ZipkinTraceLoaderOptions` | Type |
| `ZipkinTraceWriter` | Writer |
| `ZipkinTraceWriterOptions` | Type |
| `ZipkinAnnotation` | Type |
| `ZipkinEndpoint` | Type |
| `ZipkinSpan` | Type |
| `ZipkinTraceLoaderWithParser` | Loader |

See the [traces module](/docs/modules/traces) for installation and related entrypoints.
