# @loaders.gl/traces/otlp

Read and write OpenTelemetry traces in JSON and Protobuf form.

```typescript
import {OtlpTraceJsonLoader, OtlpTraceLoader} from '@loaders.gl/traces/otlp';
import {OtlpTraceJsonWriter, OtlpTraceWriter} from '@loaders.gl/traces/otlp/bundled';
```

## API

| Export | Kind |
| --- | --- |
| `OtlpTraceJsonLoader` | Loader |
| `OtlpTraceLoader` | Loader |
| `OtlpTraceLoaderOptions` | Type |
| `OtlpEventArrowTable` | Type |
| `OtlpLinkArrowTable` | Type |
| `OtlpResourceArrowTable` | Type |
| `OtlpScopeArrowTable` | Type |
| `OtlpSpanArrowTable` | Type |
| `OtlpTrace` | Type |
| `OtlpTraceBatch` | Type |
| `OtlpTraceTableName` | Type |
| `OtlpTraceJsonWriter` | Writer |
| `OtlpTraceJsonWriterOptions` | Type |
| `OtlpTraceWriter` | Writer |
| `OtlpTraceWriterOptions` | Type |
| `OtlpTraceLoaderWithParser` | Loader |
| `OtlpTraceJsonLoaderWithParser` | Loader |
