# @loaders.gl/tiles/tileset-2d

Manage selection, loading, caching, and refinement of two-dimensional tiles.

```
import {Tile2DHeader, Tileset2D, STRATEGY_DEFAULT, STRATEGY_NEVER} from '@loaders.gl/tiles/tileset-2d';
```
