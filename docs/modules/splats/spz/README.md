# @loaders.gl/splats/spz

Read SPZ Gaussian splat data and convert it to the shared Gaussian splat representation.

```typescript
import {SPZFormat, parseSPZ, parseSPZToGaussianSplats, SPZLoader} from '@loaders.gl/splats/spz';
```

## API

| Export | Kind |
| --- | --- |
| `SPZFormat` | Utility |
| `SPZCoordinateSystem` | Type |
| `parseSPZ` | Utility |
| `parseSPZToGaussianSplats` | Utility |
| `SPZLoader` | Loader |
| `SPZLoaderWithParser` | Loader |
