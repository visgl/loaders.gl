# @loaders.gl/splats/splat

Read Gaussian splat records from the SPLAT binary format.

```
import {SPLATFormat, SPLATLoader} from '@loaders.gl/splats/splat';
```

## API[​](#api "Direct link to API")

| Export                  | Kind    |
| ----------------------- | ------- |
| `SPLATFormat`           | Utility |
| `SPLATLoader`           | Loader  |
| `SPLATLoaderWithParser` | Loader  |
