# @loaders.gl/sql/duckdb

Query DuckDB databases through the loaders.gl SQL source API.

```typescript
import {DuckDBSQLSource, DuckDBSQLDataSource} from '@loaders.gl/sql/duckdb';
```

## API

| Export | Kind |
| --- | --- |
| `DuckDBSQLSource` | Source |
| `DuckDBSQLDataSource` | Source |

See the [sql module](/docs/modules/sql) for installation and related entrypoints.
