# @loaders.gl/sql/arrow

Query Arrow tables through the SQL source interface.

```typescript
import {ArrowTableSource, explainArrowTableQuery, queryArrowTable} from '@loaders.gl/sql/arrow';
```

## API

| Export | Kind |
| --- | --- |
| `ArrowTableSource` | Source |
| `explainArrowTableQuery` | Utility |
| `queryArrowTable` | Utility |
| `ArrowQueryOptions` | Type |
| `ArrowTableSourceOptions` | Type |

See the [sql module](/docs/modules/sql) for installation and related entrypoints.
