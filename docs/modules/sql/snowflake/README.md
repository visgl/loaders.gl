# @loaders.gl/sql/snowflake

Query Snowflake through the loaders.gl SQL source API.

```typescript
import {SnowflakeSQLSource, SnowflakeSQLDataSource} from '@loaders.gl/sql/snowflake';
```

## API

| Export | Kind |
| --- | --- |
| `SnowflakeSQLSource` | Source |
| `SnowflakeSQLDataSource` | Source |

See the [sql module](/docs/modules/sql) for installation and related entrypoints.
