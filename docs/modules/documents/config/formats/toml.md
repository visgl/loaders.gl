# TOML

TOML (Tom's Obvious, Minimal Language) is a configuration file format designed to be easy to read
and map unambiguously to a hash table.

- _[`@loaders.gl/documents`](/docs/modules/documents/config)_
- _[`TOMLLoader`](/docs/modules/documents/config/api-reference/toml-loader)_
- _[TOML specification](https://toml.io/en/)_

The loaders.gl TOML parser supports tables, arrays of tables, dotted keys, strings, arrays, inline
tables, booleans, numeric bases, special floats, and TOML date/time values.
