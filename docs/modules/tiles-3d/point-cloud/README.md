# @loaders.gl/tiles-3d/point-cloud

Traverse and load tiled point clouds through a shared runtime.

```typescript
import {PointCloudTileset, PointCloudTile, PointCloudTileLoader} from '@loaders.gl/tiles-3d/point-cloud';
```
