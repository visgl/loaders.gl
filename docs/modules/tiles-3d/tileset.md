# @loaders.gl/tiles-3d/tileset

Traverse, load, and cache 3D tilesets.

```
import {Tileset3D, getTileset3DTraversalSnapshot, traverseTilesetContents, isTileset3DSource} from '@loaders.gl/tiles-3d/tileset';
```
