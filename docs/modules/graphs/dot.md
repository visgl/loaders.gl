# @loaders.gl/graphs/dot

Read Graphviz DOT graphs, including nodes, edges, attributes, and subgraphs.

```
import {DOTLoader} from '@loaders.gl/graphs/dot';
```

## API[​](#api "Direct link to API")

| Export                | Kind   |
| --------------------- | ------ |
| `DOTLoader`           | Loader |
| `DOTGraphData`        | Type   |
| `DOTMetadata`         | Type   |
| `DOTSubgraph`         | Type   |
| `DOTOutput`           | Type   |
| `DOTLoaderOptions`    | Type   |
| `DOTLoaderWithParser` | Loader |

See the [graphs module](https://loaders.gl/docs/modules/graphs.md) for installation and related entrypoints.
