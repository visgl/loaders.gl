# @loaders.gl/graphs/dot

Read Graphviz DOT graphs, including nodes, edges, attributes, and subgraphs.

```typescript
import {DOTLoader} from '@loaders.gl/graphs/dot';
```

## API

| Export | Kind |
| --- | --- |
| `DOTLoader` | Loader |
| `DOTGraphData` | Type |
| `DOTMetadata` | Type |
| `DOTSubgraph` | Type |
| `DOTOutput` | Type |
| `DOTLoaderOptions` | Type |
| `DOTLoaderWithParser` | Loader |

See the [graphs module](/docs/modules/graphs) for installation and related entrypoints.
