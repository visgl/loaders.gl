# @loaders.gl/graphs/graphml

Read GraphML XML documents into node and edge tables with graph attributes and defaults.

```typescript
import {GraphMLLoader} from '@loaders.gl/graphs/graphml';
```

## API

| Export | Kind |
| --- | --- |
| `GraphMLLoader` | Loader |
| `GraphMLLoaderOptions` | Type |
| `GraphMLLoaderWithParser` | Loader |

See the [graphs module](/docs/modules/graphs) for installation and related entrypoints.
