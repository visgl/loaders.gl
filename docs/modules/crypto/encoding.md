# @loaders.gl/crypto/encoding

Encode digests and convert base64 data.

```
import {encodeNumber, encodeHex, encodeBase64, asciiToBase64} from '@loaders.gl/crypto/encoding';
```

## API[​](#api "Direct link to API")

| Export          | Kind    |
| --------------- | ------- |
| `encodeNumber`  | Utility |
| `encodeHex`     | Utility |
| `encodeBase64`  | Utility |
| `asciiToBase64` | Utility |
| `base64ToAscii` | Utility |

See the [crypto module](https://loaders.gl/docs/modules/crypto.md) for installation and related entrypoints.
