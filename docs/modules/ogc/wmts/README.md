# @loaders.gl/ogc/wmts

APIs for WMTS data in the ogc module.

```typescript
import {WMTSCapabilitiesLoader} from '@loaders.gl/ogc/wmts';
```

## API

| Export | Kind |
| --- | --- |
| `WMTSCapabilitiesLoaderOptions` | Type |
| `WMTSCapabilities` | Type |
| `WMTSCapabilitiesLoader` | Loader |

See the [ogc module](/docs/modules/ogc) for installation and related entrypoints.
