# @loaders.gl/ogc/wfs

APIs for WFS data in the ogc module.

```
import {_WFSCapabilitiesLoader} from '@loaders.gl/ogc/wfs';
```

## API[​](#api "Direct link to API")

| Export                   | Kind   |
| ------------------------ | ------ |
| `_WFSLoaderOptions`      | Type   |
| `_WFSCapabilities`       | Type   |
| `_WFSCapabilitiesLoader` | Loader |

See the [ogc module](https://loaders.gl/docs/modules/ogc.md) for installation and related entrypoints.
