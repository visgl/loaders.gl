# @loaders.gl/ogc/gml

APIs for GML data in the ogc module.

```typescript
import {GMLLoader, _GMLLoader} from '@loaders.gl/ogc/gml';
```

## API

| Export | Kind |
| --- | --- |
| `GMLLoaderOptions` | Type |
| `_GMLLoaderOptions` | Type |
| `GMLLoader` | Loader |
| `_GMLLoader` | Loader |
| `GMLLoaderWithParser` | Loader |

See the [ogc module](/docs/modules/ogc) for installation and related entrypoints.
