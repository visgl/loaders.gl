# @loaders.gl/ogc/csw

APIs for CSW data in the ogc module.

```
import {CSWCapabilitiesLoader, CSWDomainLoader, CSWRecordsLoader} from '@loaders.gl/ogc/csw';
```

## API[​](#api "Direct link to API")

| Export                         | Kind   |
| ------------------------------ | ------ |
| `CSWCapabilitiesLoaderOptions` | Type   |
| `CSWCapabilities`              | Type   |
| `CSWCapabilitiesLoader`        | Loader |
| `CSWDomain`                    | Type   |
| `CSWDomainLoader`              | Loader |
| `CSWRecords`                   | Type   |
| `CSWRecordsLoader`             | Loader |

See the [ogc module](https://loaders.gl/docs/modules/ogc.md) for installation and related entrypoints.
