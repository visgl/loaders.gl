# @loaders.gl/ogc/gml

APIs for GML data in the ogc module.

```
import {GMLLoader, _GMLLoader} from '@loaders.gl/ogc/gml';
```

## API[​](#api "Direct link to API")

| Export                | Kind   |
| --------------------- | ------ |
| `GMLLoaderOptions`    | Type   |
| `_GMLLoaderOptions`   | Type   |
| `GMLLoader`           | Loader |
| `_GMLLoader`          | Loader |
| `GMLLoaderWithParser` | Loader |

See the [ogc module](https://loaders.gl/docs/modules/ogc.md) for installation and related entrypoints.
