# Legacy tile-converter CLI

The legacy `tile-converter-v4` command and `@loaders.gl/tile-converter/v4` package entry point were removed. Use the [current CLI reference](https://loaders.gl/docs/modules/tile-converter/cli-reference/tile-converter-v5.md) to migrate scripts to `tile-converter inspect`, `convert`, and `validate`.

For workflows that still depend on the legacy flags, pin `@loaders.gl/tile-converter@5.0.0-rc.2`. See the [legacy reference for that release](https://github.com/visgl/loaders.gl/blob/v5.0.0-rc.2/docs/modules/tile-converter/cli-reference/tile-converter.md).
