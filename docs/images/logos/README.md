# Format Logos

This directory holds source logo assets for the documentation format gallery. The website delivery
copies live in `website/static/images/format-logos` and should use the same filenames.

Dedicated ecosystem marks are preferred when a format has a stable, appropriate source. For formats
without one, the gallery uses a format-specific neutral SVG badge rather than implying affiliation
with an unrelated organization. `format-logo.svg` remains the final generic fallback.
