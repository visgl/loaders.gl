# Format Logos

This directory holds source logo assets for the documentation format gallery.

Where a format does not have a dedicated logo in the repository, the gallery uses
`format-logo.svg`, a neutral file-format badge. The website copies these assets to
`website/static/images/format-logos` for delivery.

The YAML mark is sourced from the [YAML common image assets](https://github.com/yaml/yaml-common/blob/main/image/yaml-logo.svg).
The TOML mark is sourced from the [official TOML logo](https://github.com/toml-lang/toml/blob/main/logos/toml.svg).
