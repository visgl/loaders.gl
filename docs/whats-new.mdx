## v5.0

loaders.gl 5 organizes loaders, writers, and sources by data family. Install a package
and import the format you use. See the [Upgrade Guide](./upgrade-guide.md#upgrading-to-v50)
for stable v4 migrations.

- **Cloud and table data.** [Table sources](./modules/tables/README.md) support column and
  row selection across Parquet, Arrow, and lakehouse formats. [Core queries](./modules/core/query/README.md)
  push supported filters and projections to the source. [SQL](./modules/sql/README.md)
  provides an opt-in DuckDB integration.
- **Raster and scientific data.** [Raster](./modules/raster/README.md) supports range reads
  and terrain meshes. [Scientific](./modules/scientific/README.md) groups multidimensional
  arrays and VTK, NRRD, and PDB formats.
- **3D content and tiles.** [Scene](./modules/scene/README.md) groups glTF, Draco, and mesh
  formats. [Tile Converter](./modules/tile-converter/README.md) defaults to the v5 engine.
- 🧪 **Satellite orbit elements (experimental).** [`OMMLoader`](./modules/geospatial/omm/api-reference/omm-loader.md)
  reads the SGP4 subset of CCSDS OMM in JSON and KVN. It validates GP metadata and epoch dates.
  In KVN, it accepts metadata and data delimiters and skips optional blocks such as covariance.
  [`TLELoader`](./modules/geospatial/tle/api-reference/tle-loader.md)
  reads two-line element sets. Both return one table schema with the OMM keyword names.
- **Documents and images.** [Documents](./modules/documents/README.md) groups text and
  structured formats. [Images](./modules/images/README.md) adds OpenEXR, color lookup
  tables, and measured lighting profiles.
- **Optional implementations.** Use metadata loaders with `load()` and `parse()`.
  Import a format's bundled loader when you need its parser immediately, such as with
  `parseSync()`.

## v4.5

Added Gaussian splat loaders, Chrome Trace parsing, experimental TypeScript Parquet, and Mapbox and MapLibre style loading.

## v4.4

Added MapLibre Tile support and unified texture outputs, including Radiance HDR.

## v4.3

Improved loader type inference and introduced typed source and range request interfaces.

## v4.2

Improved loader object typing and moved the website examples to deck.gl v9.

## v4.1

Added GeoArrow loading and required Apache Arrow 15 or later.

## v4.0

Added typed loaders, more writers, file format documentation, and support for Node.js 18 and 20.

## v3.4

Moved the documentation to Docusaurus and upgraded to TypeScript 5.

## v3.3

Added official Vite support and moved most examples to Vite.

## v3.2

Added support for the recommended Arrow file and stream MIME types.

## v3.1

Added KTX2 support to BasisLoader and introduced KTX2BasisWriter.

## v3.0

Improved TypeScript support and expanded typed loaders and options.

## v2.3

Added Shapefile loading, more compression codecs, and binary geospatial output.

## v2.2

Published TypeScript declarations for packages with public functions and classes.

## v2.1

Expanded geospatial loaders and 3D content support.

## v2.0

Added loader-specific options, composite loaders, and dynamic loading of heavy decoders.

## v1.3

Improved 3D Tiles support and the glTF 2 parser.

## v1.2

Added binary file auto-detection and improved Arrow support in Node.

## v1.1

Introduced GLTFLoader and early 3D Tiles support.

## v1.0

Initial release.
