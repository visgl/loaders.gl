# Guide

Start with [Get Started](https://loaders.gl/docs/developer-guide/get-started.md), then explore the concepts and module guides that match your application. The guides explain how to load, write, and work with data; each module's API section documents its package exports and subpaths.

## Foundations[​](#foundations "Direct link to Foundations")

* [Get Started](https://loaders.gl/docs/developer-guide/get-started.md): install loaders.gl and load your first dataset.
* [3D data formats](https://loaders.gl/docs/developer-guide/3d-data-formats.md): choose formats for meshes, point clouds, and tiled scenes.
* [JavaScript APIs](https://loaders.gl/docs/developer-guide/concepts/javascript-apis.md): understand the asynchronous, synchronous, and streaming APIs.
* [Streaming](https://loaders.gl/docs/developer-guide/concepts/streaming.md): process data incrementally.
* [Worker threads](https://loaders.gl/docs/developer-guide/concepts/worker-threads.md): move parsing off the main thread.

## Module guides and API[​](#module-guides-and-api "Direct link to Module guides and API")

Browse [Modules](https://loaders.gl/docs/modules.md) by data family. Each module header opens its overview. Guide pages cover workflows and concepts, while API section headers open the main package and subpath pages. Modules with a single guide link directly to that page.

* [Core](https://loaders.gl/docs/modules/core.md): loading, writing, sources, and shared utilities.
* [Tables](https://loaders.gl/docs/modules/tables.md): tabular data and Arrow.
* [Geospatial](https://loaders.gl/docs/modules/geospatial.md): geospatial formats and geometry.
* [Images](https://loaders.gl/docs/modules/images.md): images, textures, and video.
* [3D Tiles](https://loaders.gl/docs/modules/tiles-3d.md): tiled datasets, runtime concepts, and tutorials.
* [Services](https://loaders.gl/docs/modules/services.md): authentication and remote data access.
* [ArcGIS](https://loaders.gl/docs/developer-guide/arcgis.md): ArcGIS service workflows.
