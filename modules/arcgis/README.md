# @loaders.gl/arcgis

Framework-independent sources for ArcGIS REST services.

This package is the home for ArcGIS service integrations, including FeatureServer, ImageServer, and MapServer sources. The initial release provides a focused package boundary while the implementations remain shared with `@loaders.gl/wms`; existing WMS imports continue to work during the migration.

For documentation, visit the [loaders.gl website](https://loaders.gl/docs).
