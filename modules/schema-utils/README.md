# @loaders.gl/schema-utils

This module contains:

- Classes and APIs for manipulating tabular data output from loaders.gl table category loaders (CSV, JSON, ...).

[loaders.gl](https://loaders.gl/docs) is a collection of framework-independent 3D and geospatial parsers and encoders.

Please visit the [website](https://loaders.gl).

Arrow table transport and buffer ownership helpers are available from `@loaders.gl/schema-utils/arrow-transport`, without depending on the grouped table format engines. See the [schema utilities documentation](../../docs/modules/schema-utils/README.md).
