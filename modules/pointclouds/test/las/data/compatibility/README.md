# LASzip compatibility-mode fixtures

Each modern LAS 1.4 file contains 64 deterministic points in PDRF 6, 7, 8, 9, or 10, plus a one-byte `quality` Extra Bytes descriptor before the compatibility fields. Coordinates, classification codes above 31, return counts up to 15, all classification flags and scanner channels, positive and negative scan-angle extremes, RGB/NIR, and waveform offsets above JavaScript's safe integer range vary across the records.

The matching `*-compatible.laz` files were generated by LASzip 3.5.1 using its DLL API with `laszip_request_compatibility_mode(..., true)` before opening the writer. The `*-compatible.las` files contain the independently decompressed legacy records and the same compatibility/Extra Bytes VLRs, with the compression VLR removed and the physical point-data offset adjusted.

LASzip's compatibility reader reconstructed every original modern raw record byte for byte for all five formats. Tests compare every represented column with the modern source LAS, and verify that raw decompression retains the physical legacy records.
