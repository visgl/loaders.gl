# @loaders.gl/csv

This POC keeps this package as a compatibility entry point. Its implementation is owned by `@loaders.gl/tables`. See the [grouped package guide](../../docs/developer-guide/grouped-packages.md) for the new imports and migration boundaries.

This module contains a table loader for the CSV and DSV formats.

[loaders.gl](https://loaders.gl/docs) is a collection of framework-independent visualization-focused loaders (parsers).
