# @loaders.gl/documents

XML, HTML, YAML, TOML, BSON, and Markdown loaders. The root exports lightweight loader
metadata and public types. Use flat implementation entrypoints such as
`@loaders.gl/documents/xml-loader` for `XMLLoaderWithParser` and
`@loaders.gl/documents/bson-codec` for synchronous BSON helpers.

See the [documents module guide](../../docs/modules/documents/README.md).
