# @loaders.gl/potree

This module contains loaders for the [potree](https://github.com/potree/potree) format.

`PotreeMetadataSchema` validates Potree `cloud.js` metadata at runtime and provides the inferred `PotreeMetadata` TypeScript type. The equivalent generated JSON Schema is available from `@loaders.gl/potree/potree-metadata.schema.json`.

[loaders.gl](https://loaders.gl/docs) is a collection of framework-independent 3D and geospatial loaders (parsers).

For documentation please visit the [website](https://loaders.gl).
