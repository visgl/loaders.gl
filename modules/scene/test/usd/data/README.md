# Binary USD fixtures

Tiny official OpenUSD test assets, distributed under the retained OpenUSD-LICENSE.txt:

- sphere.usdc and sphere.usda: pxr/usd/bin/usddiff/testenv/testDiffToolVariousUsdFormats/a.usdc and a.usda.
- attributes.usdc: pxr/usdImaging/bin/testusdview/testenv/testUsdviewFileArguments/test.usdc.

Source: https://github.com/PixarAnimationStudios/OpenUSD (dev tree, fetched November 6, 2026).
These fixtures exercise the binary decoder against files produced independently
of loaders.gl; no network access is needed during tests.

triangle.usda is an original MIT-licensed loaders.gl fixture. triangle.usdc was
produced from it with the existing macOS /usr/bin/usdcat CLI (crate 0.8.0), which
is only a fixture-generation tool and is not a runtime or test dependency.

The original siblings.usda/usdc pair exercises authored root and child order.
The original triangle pair also includes unsigned compressed values and a token
array for decoded-limit regressions. Binary counterparts were generated using
usdcat; this is fixture provenance, not a runtime or test dependency.

large-indices.usdc is an original MIT fixture generated by usdcat from an Xform
with custom int[] indices containing one million zeros. Its encoded size is tiny,
but its decoded-scale regression runs only in the hermetic slow lane.
The triangle fixture also exercises vector-array and asset-path time samples.

wide-assembly.usdc is an original MIT fixture generated by usdcat from an Xform
containing 12,000 numbered Xform children, each containing one Mesh. The small
binary fixture exercises iterative path reconstruction in the hermetic slow lane.

## Authored-value and USDZ fixtures

The dictionary, dictionary-depth and dictionary-special-keys USDA files are
original MIT fixtures by vis.gl contributors. Their USDC counterparts were
generated with usdcat. They cover layer/prim metadata, nested and empty values,
asset paths, primitive arrays, nesting limits, and prototype-sensitive keys.

The two dictionary USDZ archives were generated with usdzip (stored entries and
64-byte data alignment). dictionary.usdz has dictionary.usdc as its root.
dictionary-binary-usd.usdz has that same binary content renamed root.usd, followed
by a small secondary.usda layer containing an Xform named Secondary. These
fixtures require no native tools at test time and add no package dependency.

The embedded-assets directory contains original MIT-licensed vis.gl fixture data:
small USDA layers, one-pixel PNG images, a JPEG converted with macOS sips, and a
three-byte binary resource. embedded-assets.usdz packages its ASCII scene and
resources using usdzip. parts/model.usdc was generated from parts/model.usda
with usdcat; embedded-assets-binary.usdz packages that binary root and the same
PNG/JPEG resources. Native tools generate fixtures only; tests use checked-in bytes.
