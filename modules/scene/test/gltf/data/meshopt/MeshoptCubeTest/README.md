# MeshoptCubeTest fixture

This directory contains the `glTF-Meshopt` JSON and binary files from KhronosGroup's
[`glTF-Sample-Assets`](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/MeshoptCubeTest)
repository at commit `2bac6f8c57bf471df0d2a1e8a8ec023c7801dddf`.

The fixture is published under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
Its reference images are intentionally omitted because the loader tests disable image loading.
