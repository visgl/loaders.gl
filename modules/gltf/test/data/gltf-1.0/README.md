# Original glTF 1 samples

`Box.gltf` and `BoxAnimated.gltf` are unchanged embedded glTF 1 files from
[Khronos glTF-Sample-Models](https://github.com/KhronosGroup/glTF-Sample-Models/tree/d7a3cc8e51d7c573771ae77a57f16b0662a905c6/1.0),
pinned at `d7a3cc8e51d7c573771ae77a57f16b0662a905c6`.

Both were donated by Cesium for glTF testing. See the original attribution for
[Box](https://github.com/KhronosGroup/glTF-Sample-Models/blob/d7a3cc8e51d7c573771ae77a57f16b0662a905c6/1.0/Box/README.md)
and [BoxAnimated](https://github.com/KhronosGroup/glTF-Sample-Models/blob/d7a3cc8e51d7c573771ae77a57f16b0662a905c6/1.0/BoxAnimated/README.md).

The files are self-contained and together occupy less than 36 KiB. The conversion tests
and interactive example use the same files. Best-effort conversion approximates their
conventional diffuse materials; legacy shaders and premultiplied alpha are reported.
Khronos validation checks structural glTF 2 conformance, not shader or appearance equivalence.
