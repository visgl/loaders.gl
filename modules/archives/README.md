# @loaders.gl/archives

ZIP and TAR archive loaders and writers.

Supported formats: ZIP, TAR.

ZIP and TAR loaders and writers. Import `@loaders.gl/archives/zip` or `@loaders.gl/archives/tar` for format-specific APIs. The package root exports metadata-only loaders and writers.

See the [documentation](https://loaders.gl/docs/modules/archives).
