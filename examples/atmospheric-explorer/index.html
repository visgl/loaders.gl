Atmospheric Explorer

Global atmospheric analysis

Explore ECMWF Integrated Forecasting System (IFS) atmospheric analysis fields in the browser. This example uses loaders.gl for scientific array access and deck.gl for interactive globe rendering.

The cloud-native archive was prepared and published by Beyond Weather using Icechunk and Zarr. The explorer is an independent vis.gl example, not an official ECMWF or Beyond Weather product.

Modifications and distribution

Beyond Weather prepared and published the cloud-native archive, including selection of variables and pressure levels, conversion from GRIB to Icechunk Zarr, and lossy bit rounding. This explorer selects fields and maps numerical values to colors and geographic points.

Data distribution: AWS Open Data and Earthmover.
