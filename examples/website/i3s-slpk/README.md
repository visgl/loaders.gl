# I3S SLPK example

This standalone example renders an I3S Scene Layer Package (SLPK) selected from the local
filesystem or supplied as an HTTP URL.

Remote servers must allow cross-origin requests and support HTTP byte-range responses (HTTP 206
with a valid Content-Range header).

## Usage

From the repository root:

```bash
yarn workspace i3s-slpk-loaders-example start
```
